## How it works

`main.py` holds a single five-word confession in a constant. When run, it
asserts the line is non-empty, exactly one line, 1–5 words, and 1–88
characters, then writes it to `/output/entry.txt` with no trailing newline.
A flat denial about something the agent obviously did — short, brazen, and
instantly believable.
